# Freya 水印相机 · 批量加水印

纯前端（HTML + CSS + JS，零依赖、零构建、无需服务器）的图片水印工具：
**拖拽导入 → 调参数 → 批量导出 ZIP**，所有处理都在浏览器本机完成，图片不会上传到任何地方。

直接用浏览器打开 `index.html` 就能用；也可以把 `index.html` 丢到 GitHub Pages / 任意静态托管。

---

## 快速开始

1. 双击 `index.html`（或把它上传到 Pages 后访问）
2. 把图片**拖进页面**（支持一次拖多张，也支持直接 Ctrl+V 粘贴）
3. 在左侧调整参数，右侧实时预览
4. 点 **批量导出 ZIP**（单张则点「导出当前」），浏览器会下载打包好的 ZIP

> 快捷键：`Ctrl/⌘ + S` 导出；选中队列后按 `←↑→↓` 微调水印边距（按住 Shift 步长变大）。

> **参数会自动保存**：面板上**全部设置**（含行内容、位置、颜色、字号、以及导出格式/质量/文件名模板/长边像素/适应窗口）
> 改动后立即写入浏览器 `localStorage`，下次打开自动恢复。**点「恢复默认」会同时清掉存档**，刷新后也回到默认值。
> 图片队列不会持久化（刷新即清空）；`localStorage` 不可用时自动降级为不保存。

> **数值可以直接改**：面板上每个数值（滑块右侧那个彩色数字）**点一下就能就地编辑**——
> 就在原位置换成同尺寸的输入框，**不新增元素、排版不会变**。回车或点别处提交、`Esc` 取消；
> 超出范围按滑块区间夹取（如标题字高 50~200），非法输入自动还原成原值。

## 功能

### 导入
- 拖拽 / 点击选择 / 剪贴板粘贴，支持 JPG、PNG、WebP 等浏览器可解码的格式
- 自动读取 **EXIF 拍摄时间**（没有则用文件修改时间）
- 超长边图片自动降采样到 8192px 以内再预览，避免浏览器画布崩溃

### 水印样式（表格部分按需求调整，见下）
- **左下角信息表格**：圆角卡片 + 蓝色顶栏 + 标题 + 黄色圆点 + 多行「标签 : 值」
- 顶栏标题、主色、圆点颜色、表格底色、文字颜色全部可调
- **字体默认黑体（SimHei）且全表加粗**；**标题文字属性跟随行文字**（字号、加粗、字体一起变）
- **标题字号 / 字高 / 行高 / 顶栏高度四个滑块都在面板上可调**（互不绑定）：
  `标题字号` 等比放大字号，`标题字高` 只把字形**纵向拉高**（横向排布不变，
  且以**行中心为锚点**缩放，居中排版不会跑偏）
- `标题行高` 1.5 = 字号 ×1.5；`顶栏高度加成` 180% = 行高 ×1.8
- **标题字距是绝对像素（默认 5px）**，且放不下时**自动继续收紧**，保证标题单行不折行
- **字高 = 参考字高 ×1.2**（只把文字变高，**表格宽度不变**，仍是参考图的 931/1773 比例）
- 值列**占满表格剩余宽度**，所以字变大后长文本反而更少折行
- **标签内字距**（默认 `0.185em`）与**冒号→值间距**（默认 `0.20em`）都可单独调，
  两者比例是按水印相机 APP 的成图实测校准的；标签列会按最长标签自适应放宽，不会被字距顶出去
- 行高 = 字号 ×1.35、行间距 = 字号 ×0.18（均可调），正文字距默认 `0.00em`
- **行间有 1px 灰色分隔线**（固定 1px，不随图片缩放变化）
- **圆角默认 16**、投影浓度、**表格不透明度可单独调**（与「整体不透明度」相乘）
- 表格行文本**自动折行**（长内容换行，超长文本自动增加行高）
- 字高加大后表格变高，方形/小图可能放不下：引擎会**等比缩小整个表格块**，保证不超出图片（见「已知限制」）

### 右下角防伪（固定锚定图片右下角）
- **位置固定：无论水印表格放在哪个角，防伪标识始终贴图片右下角**（右边距 = 水平边距，底边距 = 垂直边距）
- 使用你提供的 logo 图片（已在构建时以 base64 内嵌进 `index.html`，无需额外资源）
- **防伪码每张图片导出时重新随机生成**（`crypto.getRandomValues`，字符集去掉了 `0/O/1/I/Z` 等易混字符）
- 防伪码与「防伪」标签均为**纯白加粗字体、无底纹**，只带一层很淡的黑色投影保证在浅色背景上仍可读
- **默认 14 位**（与参考图一致），可在 4~24 位之间调整
- **「防伪码字号」默认 128%**，滑块可调 40%~220%：滑块多大就是多大，
  只有位数多到字身会互相重叠时才按可用宽度收敛
- 码字右对齐到 logo 右边界、向左排布，「防伪」标签贴在其左侧；间距已收紧（`0.12em`）
- 位数、标签文字、字号、logo 缩放均可调

### 位置与批量
- 水印**表格**可放 左下 / 右下 / 左上 / 右上（防伪标识不受影响，始终在图片右下角）
- 表格若被放到右下，会**自动上移让开防伪标识**，两者不重叠
- 缩放、水平/垂直边距、不透明度可调
- 批量队列（缩略图切换、单张删除、清空）
- 导出格式 JPG / PNG / WebP + 质量可调
- 可设置「长边最大像素」统一压缩尺寸
- 文件名模板支持变量：`{name}` `{date}` `{time}` `{code}` `{i}` `{w}` `{h}`
- ZIP 由内置的零依赖打包器生成（STORE 方式，标准 ZIP，Windows/macOS 都能解压；文件名 UTF-8）

## 部署到 GitHub Pages

```bash
# 1. 只需要一个文件
cp index.html /path/to/your-repo/

# 2. 提交
git add index.html && git commit -m "add watermark tool" && git push
```

然后在仓库 **Settings → Pages** 里选择分支（`main` / `root`），保存后访问
`https://<用户名>.github.io/<仓库名>/` 即可。

`index.html` 是完全自包含的：CSS、JS、logo 图片全部内联，**没有任何外部请求、没有 CDN 依赖**。

## 参考图还原依据

默认参数大部分是从参考图（1773×2364）逐像素量出来的，比例都换算成「相对短边的比值」
写进 `src/render.js` 的 `M` 常量表。**表格的宽度、字高、行距、行间分隔线已按需求主动调整，
不再追求与参考图 1:1**（`tools/verify.js` 会把这几项单独标成「按需求调整」，不计入还原度偏差）。

| 项目 | 参考图实测 | 代码常量 / 当前默认 |
|---|---|---|
| 表格尺寸 | 931 × 335 px，位于左下（左边距 39、底边距 40） | `M.tableW = 0.5253`（**宽度保持参考比例**；字高加大后总高变为 ~366） |
| 顶栏 | 纯色 `#15a7fa`，高 96 px（实测整条颜色一致，**没有渐变**） | `M.headerH = 0.0542` ×`titleFontScale` |
| 标题 | 字号 44 px、字距 0.34em、白色、垂直居中 | `M.headerFont = 0.0248`；字距改为**绝对 8px** |
| 圆点 | 直径 29 px、中心距表格左边 49 px、`#f4c647` | `M.dotD` / `M.dotX` |
| 正文 | 字号 40 px、字距 0.10em、行距 60 px（1.5 倍行高），黑字白底 | `M.bodyFont` ×`bodyFontScale 1.2`、字距 `0.06em` |
| 行高 / 行间距 | 行距 60 px（1.5 倍行高），行间无分隔 | `lineHeightRatio 1.35` / `rowGapRatio 0.18` + `M.rowSepH = 1px` 灰线 |
| 内边距 | 左右 23.4 / 顶栏上 9 / 正文前 26 / 底 40 | `M.padX` 等 |
| 正文列 | 左内边距 21，标签列到 x324，值列 x359..921 | `M.labelColW` / `M.labelGap`；值列**占满表格剩余宽度**（约 590 px） |
| 表格底色 / 圆角 | `#f5f5f5` / 约 21 px | 默认值 / `radius` |
| 右下 logo | 宽 266 px，**锚定图片右下角**（左边距 1468、上边距 2166，防伪码行下沿 = 底边距 40） | `M.logoW = 0.1501` |

`node tools/verify.js` 会把当前代码算出来的版式和这些实测值逐项对比：
**表格宽度、内边距、顶栏、圆点、logo 尺寸等仍与参考图一致**；
只有「正文字号（×1.2）」与「行基准间距」是按需求有意调整的。
表格高度随之从 335 变为 ~366，属于字高加大的必然结果。

> 说明：蓝色顶栏取 96px（实测在 96~107 之间，因为卡片顶部有 1~2px 的抗锯齿过渡）。
> 这些是「按比例缩放」与「像素绝对一致」之间的取舍 —— 水印要能适配任意尺寸的图片，
> 所以统一用相对短边的比例。
>
> 防伪标识：参考图里它和表格底边齐平（底边距 17px），代码里改成「锚定图片右下角、
> 底边距 = 垂直边距」，这样把表格移到别的角时防伪仍在右下，位置才是稳定的。
> 防伪码样式按参考图取「纯白 + 加粗 + 无底纹」，默认位数已改为与参考图一致的 14 位。

`tools/analyze-ref.js` 可以随时重新量一遍参考图（需要先跑 `tools/init-ref.ps1`）：

```bash
powershell -ExecutionPolicy Bypass -File tools/init-ref.ps1   # 生成 tools/_data/ref_rgb24.raw
node tools/analyze-ref.js                                     # 输出上表所有实测值
```

## 开发期校验脚本

不需要浏览器即可跑（Node ≥ 18）：

```bash
node tools/check.js        # 静态检查：DOM ID、参数名、资源引用、CSS 类、文件编码
node tools/test-panel.js   # 面板交互：点击数值就地编辑、夹取/还原/取消、参数持久化（31 项）
node tools/test-render.js  # 渲染断言：93 项几何/颜色/文字/边界用例
node tools/test-zip.js     # ZIP 打包正确性（CRC32、UTF-8 文件名、EOCD）
node tools/verify.js       # 版式与参考图实测值对比
node tools/analyze-ref.js  # 从参考图重新量取几何与配色（需要 _ref_black.jpg）
node tools/preview-code-line.js  # 导出右下防伪块的 SVG 预览（目视校对 10/14/24 位码）
node build.js              # 重新构建 index.html
```

其中 `test-render.js` 用一个「记录型 canvas stub」跑真实绘制流程，
断言表格坐标/尺寸/文字位置/logo 位置/防伪码位置与样式是否与参考图一致 —— 61 项全部通过。

`preview-code-line.js` 会把右下防伪块（logo + 防伪码行）单独画一遍并导出
`tools/_data/code-line-*.svg`（附 `.html`，浏览器可直接打开放大看），用来目视校对
10 / 14 / 24 位码的字号、间距与是否越界；红色虚线是 `marginX` / `marginY` 边距参考线。

## 已知限制

- **超大图**：单边超过浏览器画布上限（Chrome 约 65535px，且总面积有限制）时，
  该图片会被跳过并提示，可设置「长边最大像素」后重试。
- **ZIP 在内存中组装**：批量几十张大图时占用内存较高；ZIP 使用 STORE（不压缩），
  因为 JPG/PNG 本身已压缩，再 deflate 收益极小、速度更慢。
- **EXIF** 只解析拍摄时间，不处理 GPS；没有 EXIF 时用文件修改时间。
- 只在现代浏览器（Chrome / Edge / Firefox / Safari 新版本）测试；
  `crypto.getRandomValues` 不可用时自动退回 `Math.random`。
- **防伪标识固定右下**：若把表格也放到右下，表格会自动上移让位；
  图片很矮时表格可能上移到接近顶部，此时可改用其他角落或调小缩放/边距。
- **表格块会等比缩小**：表格已改为铺满可用宽度 + 字高 120%，方形图/小图上
  「表格 + 右下防伪」可能放不下，此时引擎会自动等比缩小整个表格块（字高、行高、内边距一起缩），
  保证不超出图片。实测：3:4 竖图字高 48px、3:2 横图 54px、400×400 小图约 11px。
  若想保住字高，可把表格移到左上/右上，或调小「缩放 / 垂直边距」。
- 纯前端无法读取本地文件系统的保存路径，导出统一走浏览器的「下载」目录。
